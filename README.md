# Smart-Sense-IoT 

An IoT lab project based on **ThingsBoard Cloud**. The project integrates data collection, device management, MQTT communication, and alarm rule configuration.

## 🛠️ Project Structure & Files:
The project includes the following components in the root directory:
- **`data_manager.py`** - Manages data flow and telemetry against the system.
- **`mqtt_init.py`** - Initializes and configures the MQTT connection to the platform.
- **`lights_relay.py`** - Manages lighting relay / output component control.
- **`panic_button.py`** - Emergency button simulator for sending urgent alerts.
- **`pulse_sensor.py`** - Pulse sensor / real-time data simulator.
- **`teacher_dashboard.py`** - Management and teacher dashboard viewing script.
- **`system_db.txt`** - System data or log file.

## 📋 Technologies & Tools:
- **Python** (including MQTT libraries)
- **ThingsBoard Cloud**
- **Git & GitHub** for version control
